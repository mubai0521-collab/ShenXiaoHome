# ShenXiaoHome：第一阶段基础改动

状态：开发基础分支，尚未完成 Windows / Android 端到端验收。
上游：death34018-hue/AionsHome；复核基线见本分支父提交，保留 MIT LICENSE。

## 本阶段已经改变的行为

- 安卓包使用独立 applicationId `com.shenxiao.home`，不覆盖上游应用。
- 安装清单只申请网络和网络状态权限；只注册精简聊天入口。
  原版的推送、通知读取、无障碍、定位、截图、相机、蓝牙、红外、录音、
  悬浮窗、开机恢复和归巢服务均未在此包注册。
- 精简入口只接受局域网、回环地址和 Tailscale 地址，不预填第三方服务器，
  不注册原生 JS 桥，不授权网页媒体请求，使用系统证书验证。
  HTTP 保留用于局域网 / Tailscale；页面子资源仍由网页决定，入口不是网络沙箱。
- `main.py` 默认只初始化数据库和恢复活跃会话，不运行上游整套后台任务。
  禁止默认恢复摄像头、PC 活动采集、社交巡逻、自动模型总结等。
  只有进程环境显式设置 `SHENXIAO_ENABLE_UPSTREAM_RUNTIME=1` 才恢复上游启动行为；
  这不是本项目第一版的建议运行方式。
- 默认聊天模型改为已有的 Codex 路线，不再从无效默认名称回退到其他供应商。
- 新建 MCP 配置为空；停用的持久化服务器不能重新连接；SSE 不再跳过证书校验。
  MCP SDK 固定到上游随附的 1.27.0，避免在线安装时直接跨到不兼容的大版本。
  已有用户主动保存的 MCP 配置不会被静默删除。
- 私有目录、OB 导出、备份、登录文件和数据库旁文件加入忽略规则。
  忽略规则只保护未跟踪的新文件，不能清除历史提交中的隐私。

## 本次独立复核发现的后续工作

1. 上游聊天 HTTP 路由和文本指令处理器仍包含摄像头、外部服务、设备控制、
   多 AI 等功能。关闭后台启动不等于禁用了这些处理器；需要逐项建立第一版能力边界。
2. 上游设置页、首页和模型目录发现逻辑仍需精简，不能把它们当作最终小家界面。
3. 精简安卓包目前只提供网页聊天壳；前台 App / 亮灭屏的自愿共享、隐私暂停、
   手机后台推送和本地规则哨兵尚未接入，不能据此宣称完整 V1 已完成。
4. OB 注入、聊天与 OB 的加密备份、独立 Codex 登录环境仍需接入和验证。
   任何真实人设、共同记忆、令牌与聊天记录都不应提交到这个公开 Fork。
5. 需要在有 Android SDK 的环境编译，并检查合并后的 Manifest 和真机权限。
   Python / JDK 检查不能代替 APK 编译或 Windows 实机验收。
